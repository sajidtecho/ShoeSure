# ShoeSure

ShoeSure is an interactive web platform built for local cobblers, shoe artisans, and footwear sellers across India. It connects customers directly with craftsmen for shoe renovation, custom painting, sole replacement, and marketplace sales at 0% commission fees.

## 🌟 Key Features
- **0% Commission Marketplace**: Empowering local artisans to keep 100% of earnings.
- **Shoe Renovation & Repair**: Doorstep pickup and delivery for shoe restoration.
- **Custom Shoe Design**: Request custom hand-painted shoe artwork.
- **Live Support**: Integrated live chat and support ticket system.
